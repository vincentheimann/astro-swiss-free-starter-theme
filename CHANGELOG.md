## [1.0.0] - 2024-12-10

### Initial Free Release

#### Features
- 🌍 **Multilingual Support** - Built-in French and German translations with easy language switching
- 🌓 **Dark Mode** - Automatic theme detection with manual toggle
- 🎨 **Starwind UI Components** - Beautiful, accessible component library
- 📱 **Fully Responsive** - Mobile-first design that works on all devices
- ⚡ **Performance Optimized** - Built with Astro for blazing-fast page loads
- 🎯 **SEO Ready** - Semantic HTML and meta tags for better search visibility
- 🖼️ **Portfolio Section** - Showcase projects with lightbox and carousel
- 👥 **Team Section** - Display team members with social links
- 💼 **Services Section** - Highlight your services with icons
- 📧 **Contact Form** - Ready-to-use contact section template
- 🎨 **Customizable** - Easy color scheme and branding customization
- 📚 **Comprehensive Documentation** - Step-by-step guides for all features
- 🆓 **100% Free & Open Source** - MIT licensed for personal and commercial use

#### Tech Stack
- Astro 5.16.0
- Tailwind CSS v4.1.17
- Starwind UI Components
- TypeScript
- Embla Carousel
- Tabler Icons
